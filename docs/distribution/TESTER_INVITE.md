# Tester invite (copy/paste)

Subject: ButterKeys early test — local typing smoother

---

Hi —

I’m looking for a few people to try **ButterKeys**, a small macOS menu bar app that fixes recurring typos locally (no cloud, no accounts).

**Install**

1. Download: https://github.com/timbenniks/butterkeys/releases/latest  
2. Open the DMG → drag ButterKeys to Applications → open from Applications  
3. Enable **Input Monitoring** and **Accessibility** for ButterKeys  
4. Quit and reopen ButterKeys  

More detail: https://github.com/timbenniks/butterkeys/blob/main/docs/download.md  

**Quick check**

In Notes, type `teh` + space → should become `the`. Undo with Control-Option-Z.

**Please report**

- Wrong corrections (especially non-English)  
- Missed typos you expected it to catch  
- Install / permission pain  

Use the issue forms, or Settings → About → Report a problem.  
Settings → Advanced → Copy redacted diagnostics is safe to paste (no sentences).

Thanks — and feel free to turn it off anytime from the menu bar.

— Tim
