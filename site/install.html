Install ButterKeys

Local-first typing correction for macOS 14+. Five minutes, two permissions.

Download ButterKeys 1.0.0

1. Get the app

  1. Download ButterKeys-1.0.0.dmg (or the latest from GitHub Releases).
  2. Open the DMG and drag ButterKeys into Applications.
  3. Eject the DMG, then open ButterKeys from Applications (not from the disk image).

2. Permissions (required)

Grant both for the copy in /Applications only:

  1. System Settings → Privacy & Security → Input Monitoring → enable ButterKeys
  2. System Settings → Privacy & Security → Accessibility → enable ButterKeys
  3. Quit ButterKeys completely and open it again from Applications

If corrections never fire, you are usually looking at the wrong binary (for example an Xcode build) or a permission that was not re-granted after a re-sign.

3. Gatekeeper / “can’t be opened”

Early builds may not yet be Developer ID–notarized. If macOS blocks the app:

  • System Settings → Privacy & Security → Open Anyway, or
  • Right-click ButterKeys → Open → confirm

4. Quick test

  1. Open Notes
  2. Type teh and a space — it should become the
  3. Undo with Control-Option-Z
  4. Teach a custom slip: select it and press Control-Option-T

What to expect

  • High-confidence personal typos are smoothed automatically
  • When unsure, ButterKeys leaves your text alone
  • Code editors use a narrower “code-safe” mode
  • Optional HUD + sound in Settings → General
  • In-app updates via Sparkle (Settings → Check for Updates…)

Feedback

File issues on GitHub (false positive, missed correction, or install/permissions), or use Settings → About → Report a problem.

For support, you can paste Settings → Advanced → Copy redacted diagnostics (no sentences or raw keystrokes).

Privacy details: Privacy policy. Typing never leaves your Mac for correction.
